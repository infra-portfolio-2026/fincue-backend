# FinCue Backend

소비 내역을 분석해 금융상품과 카드를 추천하는 서비스의 백엔드입니다.

## 주요 내용

- 금융감독원 공시 API와 카드 데이터 동기화, 상품별 스키마 정규화
- 지출 카테고리와 카드 혜택 매칭, 적금 금리 점수화
- 질문 의도에 필요한 데이터만 넣어 답하는 챗봇 API
- OAuth2 소셜 로그인과 JWT 인증

## 기술

Java · Spring Boot · Spring Security · OAuth2 · JWT · MongoDB · OpenAI API

API 키와 OAuth 클라이언트 정보는 환경변수로 바꿨습니다.


> 블라인드 채용 제출용 사본입니다. 이름·기관명·비밀값은 치환하거나 제외했고, 커밋 기록은 새로 만들었습니다. 치환된 식별자 때문에 그대로 빌드되지 않을 수 있습니다.
